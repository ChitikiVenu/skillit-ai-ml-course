Technology Stack

Tools You Will Use

Hands-on time with the same tools used in professional AI engineering and production ML workflows.

LA

LLM APIs

Large language model APIs used to integrate generative AI capabilities into applications.

HF

Hugging Face

Model hub and library ecosystem used to access, fine-tune and deploy AI models.

L

LangChain

Application framework used to build LLM-powered applications with chains and tool integrations.

P

PostgreSQL

Relational database used to store structured application and AI system data.

P

pgvector

PostgreSQL extension used to store and query vector embeddings for semantic search.

VD

Vector DBs

Purpose-built databases used to store and retrieve embeddings for RAG and semantic search.

F

FastAPI

Modern Python web framework used to build production-grade backend and AI-serving APIs.

D

Docker

Containerization platform used to package and deploy applications and AI services consistently.

M

MCP

Model Context Protocol used to connect AI agents and LLMs to external tools and data sources.
